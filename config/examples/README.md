# Exemplos de configuração

Somente configurações de exemplo, sem valores reais, podem ser versionadas nesta pasta.

Regras:

- usar nomes genéricos e caminhos fictícios;
- nunca incluir tokens, licenças, e-mails pessoais ou identificadores do equipamento;
- indicar claramente campos obrigatórios e opcionais;
- manter configurações reais fora do repositório;
- preferir formatos simples e validáveis, como JSON ou PowerShell Data Files, quando forem necessários.
