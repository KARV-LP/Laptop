# Scripts de diagnóstico

Esta pasta receberá scripts somente leitura para inventário e diagnóstico do laptop.

Requisitos mínimos:

- não alterar configurações;
- não instalar dependências automaticamente;
- não transmitir dados;
- salvar resultados somente em destino local informado;
- remover ou mascarar identificadores antes de qualquer compartilhamento;
- retornar códigos de saída e mensagens compreensíveis.

A implementação começa na Fase 1.
