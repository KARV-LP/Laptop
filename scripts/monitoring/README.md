# Scripts de monitoramento

Esta pasta receberá verificações periódicas de saúde e conformidade a partir da Fase 6.

Limites:

- sem coleta contínua invasiva;
- sem envio automático de telemetria;
- sem armazenar conteúdo de projetos, documentos ou navegação;
- frequência e retenção de logs explicitamente definidas;
- alertas baseados em condições técnicas objetivas;
- possibilidade de desativação e remoção documentada.
